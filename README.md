# MusyFit V10 — Biblioteca Visual Realista

Atualização baseada na V9, com imagens realistas integradas às telas de treino, detalhe e guia, além de Musy Progress anatômico e correção de safe-area Android.

O projeto inclui `.github/workflows/build-apk.yml` para geração do APK via GitHub Actions.

# MusyFit V9 — Exercícios ilustrados + Musy Progress anatômico

Atualização completa baseada na V8.

## Principais novidades
- Figura vetorial em **todos os exercícios** da biblioteca, do iniciante ao experiente.
- Lista de treinos com miniatura visual por exercício.
- Ao tocar em **Abrir**, tela detalhada com figura ampliada, músculos ativados, séries, repetições, descanso, carga, favorito e substituição.
- Passo a passo ilustrado com posição inicial, execução, contração, retorno e dica do Musy Coach.
- **Musy Progress** redesenhado com anatomia frente/costas, mapa muscular dinâmico, legenda, percentuais, medidas e histórico.
- Coach visual atualizado e todo o sistema anterior preservado.
- Fichas por nível, objetivo e frequência continuam ativas.
- Academia somente, ciclos de 4–6 semanas, descanso, cargas, histórico e IA preservados.

## GitHub / APK
O workflow está em `.github/workflows/build-apk.yml`. No GitHub, execute **Actions > Build MusyFit APK > Run workflow**.
